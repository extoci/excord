# Excord v0.1.1-alpha.1

This closed alpha adds recovery and installation checks to the Discord wrapper. The repository and draft release remain private. The Rust/CEF rewrite is on hold.

Download the `mac-arm64-alpha-kit.zip` or `win-x64-alpha-kit.zip` asset. Each kit includes the original installer, matching GPL source archive, SHA-256 checksums, setup guide, test checklist, and feedback form. The maintainer can forward these files without granting repository access. Updates are manual during this alpha.

## Changes

- Safe mode opens Discord without Equicord, personal plugins, themes, or custom launch arguments. It preserves the session and personal files. Use the Excord menu or Cmd/Ctrl+Alt+Shift+R to restart in safe mode.
- Invalid settings get a backup before defaults are used. Reset backs up known settings and QuickCSS and preserves personal plugin/theme folders.
- Failed navigation shows a recovery page with a working retry. Native APIs are restricted to trusted pages.
- Diagnostics export includes build versions, process metrics, and plugin/recovery counts. It excludes credentials, account IDs, URLs, filesystem paths, plugin source, and raw error text. Reports are shared manually.
- Mac screen sharing uses the native system picker and declares its system-audio capture purpose. Windows keeps its screen/window picker.
- Alpha builds skip the private update feed. The Windows installer finishes without launching the app.

## Verified build

The installers come from source `138e1fbecff4970c7a6fc57c9f81b2d38b8ce470` and [native run 39224749589](https://github.com/extoci/excord/actions/runs/39224749589).

Both native jobs passed strict ts-rust and reference TypeScript checks, 21 unit tests, the RPC check, package assertions, plugin tests against source and ASAR, and normal executable/ASAR shutdown after refreshes. Installation tests install, relaunch, and reinstall the same artifact while preserving a synthetic cookie. Recovery tests cover malformed settings, safe-mode bypass of native and renderer plugins, return to normal mode with the same session, offline retry, and diagnostics privacy. Profile paths include spaces.

The Mac bundle is ad-hoc signed and passes `codesign --verify --deep --strict`. It has no Developer ID signature or notarization. Windows is unsigned. The independent executable shutdown tests require normal exit without a forced kill; the Windows browser test permits automation cleanup only after a recorded quit event.

Equicord remains pinned to `e0e85c8d4f6dc73aac9368cf3f4b2200eac4d4b4`; the desktop base remains Equibop `27219be3566589280c0c933b04753805381d3bc8`. This retains the upstream core for compatibility. The catalog build does not prove every plugin works. There is no measured startup, RAM, or CPU comparison against Legcord or Vesktop.

## Before inviting friends

The targets are Apple silicon macOS 27+ and Windows x64. CI uses a macOS 26 Apple silicon runner. First-launch Gatekeeper/SmartScreen behavior, actual login, calls, camera, screen sharing and audio, notifications, tray behavior, and sleep/wake still need physical-device testing. Synthetic-cookie persistence is not proof of account login or migration from every older build.

Complete [the checklist](https://github.com/extoci/excord/blob/138e1fbecff4970c7a6fc57c9f81b2d38b8ce470/docs/alpha-checklist.md) on both computers before forwarding the kits. Follow [the setup and recovery guide](https://github.com/extoci/excord/blob/138e1fbecff4970c7a6fc57c9f81b2d38b8ce470/docs/closed-alpha.md) for first launch and problem reports. Record failed or untested items for friends. Do not mark live-device checks as passed based on CI.
