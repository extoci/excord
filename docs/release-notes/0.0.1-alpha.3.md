Excord 0.0.1-alpha.3 fixes the Excord Settings tab crash in 0.0.1-alpha.2 and adds Update Excord to the system tray.

## Changes

- Fixes **Excord Settings** failing to open with "Failed to render the Excord Settings tab" and React error #130. The desktop settings now receive the current Heading component instead of an undefined value. The recovery message names the existing **Verify runtime and restart** tray action.
- The system tray adds **Update Excord**. It checks for updates immediately and offers download and **Restart and update** through native dialogs, without needing Discord or Settings to load.
- The bundled runtime's chunk loader also accepts the unquoted numeric chunk IDs in Discord's current payload.
- The retired ExcordFavorites plugin is removed.
- Automated Electron checks now render the Excord Settings tab and verify Discord's startup Webpack exports.

## Known limitations

The reported Windows freeze after inactivity remains unreproduced and unresolved. This release does not claim to fix it. Automated checks do not cover every plugin, signed-in account behavior, or physical voice and screen-sharing devices.

## Updating

Use the macOS arm64 DMG for Apple silicon or the Windows x64 Setup executable. ZIP archives, matching source, updater metadata, and SHA256SUMS are included. If Excord Settings does not open on alpha.2, install this release from the Releases page.

Mac packages retain the persistent signing identity from 0.0.1-alpha.1. The app is self-signed and is not Apple-notarized; Windows packages remain unsigned.

Bundled Equicord is unchanged at 1.15.15.0 (`00abcbeea2ddf4317e02843418f267db62bcb913`), including Vencord 1.15.15 at `8d64c8be7e68616f8f116a6fff9480051aa2a0c5`.
