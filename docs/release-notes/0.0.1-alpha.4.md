Excord 0.0.1-alpha.4 restores the Windows window controls and lets Excord Settings open without the Discord window.

## Changes

- Fixes the missing minimize, maximize and close buttons on Windows. The title bar patch now matches Discord's current minified platform check again.
- Excord Settings can open in its own desktop window, so it works even when the Discord window is hidden or fails to load. Changes made there sync back into Discord.
- Activating Excord from the macOS Dock restores a hidden Discord window.

## Known limitations

The reported Windows freeze after inactivity remains unreproduced and unresolved. This release does not claim to fix it. Automated checks do not cover every plugin, signed-in account behavior, or physical voice and screen-sharing devices.

## Updating

Use the macOS arm64 DMG for Apple silicon or the Windows x64 Setup executable. ZIP archives, matching source, updater metadata, and SHA256SUMS are included. Existing installs can also use **Update Excord** in the system tray.

Mac packages retain the persistent signing identity from 0.0.1-alpha.1. The app is self-signed and is not Apple-notarized; Windows packages remain unsigned.

Bundled Equicord is unchanged at 1.15.15.0 (`00abcbeea2ddf4317e02843418f267db62bcb913`), including Vencord 1.15.15 at `8d64c8be7e68616f8f116a6fff9480051aa2a0c5`.
