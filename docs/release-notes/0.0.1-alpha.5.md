Excord 0.0.1-alpha.5 keeps the Windows app responsive after long inactivity.

## Changes

- Fixes the Windows lag and forced reload after idling. Windows deprioritized the hidden renderer and throttled its timers to once a minute, which dropped Discord's gateway connection; refocusing then forced a full reload before the client was usable. Excord now disables renderer backgrounding, intensive wake-up throttling, and energy-saver freezing on Windows.
- Update management moved into the standalone Excord Settings window and the app menu, so checks, downloads, and restarts work without opening Discord settings.

## Known limitations

The idle fix targets Windows' hidden-window throttling; it still needs confirmation on real machines during long idle periods. Automated checks do not cover every plugin, signed-in account behavior, or physical voice and screen-sharing devices.

## Updating

Use the macOS arm64 DMG for Apple silicon or the Windows x64 Setup executable. ZIP archives, matching source, updater metadata, and SHA256SUMS are included. Existing installs can also use **Update Excord** in the system tray.

Mac packages retain the persistent signing identity from 0.0.1-alpha.1. The app is self-signed and is not Apple-notarized; Windows packages remain unsigned.

Bundled Equicord is unchanged at 1.15.15.0 (`00abcbeea2ddf4317e02843418f267db62bcb913`), including Vencord 1.15.15 at `8d64c8be7e68616f8f116a6fff9480051aa2a0c5`.
