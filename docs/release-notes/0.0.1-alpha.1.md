Excord 0.0.1-alpha.1 adds Favorites and changes macOS release signing so future updates can keep a consistent signing identity.

## Updating on macOS

If you have an earlier alpha installed, quit Excord, download this release's DMG, and replace Excord in Applications. This one-time manual installation moves the app from the old ad-hoc signature to the persistent certificate. Keep your existing profile to preserve your settings and login.

The app is self-signed and is not Apple-notarized. macOS may still require you to approve opening it. No Apple Developer membership is used. Future releases must reuse this certificate for in-app updates to work.

## Changes

- ExcordFavorites adds a star below Home. Add channels, threads, DMs, and group DMs through their context menus, then organize them into categories. Favorites saves its layout locally per account and uses Discord's native conversation views. See [the Favorites guide](https://github.com/extoci/excord/blob/v0.0.1-alpha.1/docs/favorites.md).
- Mac release packages now use one persistent signing certificate. Settings explains signature rejections and directs you to a manual installer instead of offering retries of the same rejected package.
- Release checks verify the signing identity and updater ZIP. A native signing test checks compatibility between changed versions and rejects a different signer.

## Downloads

Use the macOS arm64 DMG for Apple silicon or the Windows x64 Setup executable. ZIP archives, matching source, updater metadata, and SHA256SUMS are included. This remains an alpha release; live account, voice, and screen-sharing behavior is not fully covered by automated tests.
