Excord 0.0.1-alpha.2 updates the bundled plugin runtime, simplifies Excord settings, and adds optional background update downloads.

## Changes

- Window restoration preserves normal size across minimized and fullscreen states. Reopening a window no longer reapplies an old maximized state.
- Excord settings use compact plugin rows, a clearer performance view, and expandable support information. Plugin creation appears when you need it.
- Updates download quietly by default. Turn off **Download updates automatically** in Excord Settings to choose which updates to download. Installation waits for **Restart and update**.
- Bundled Equicord advances to 1.15.15.0, including Vencord 1.15.15. Electron advances to 45.2.1, alongside desktop and supporting dependency updates.
- Desktop updates add spellcheck language names and search, apply the user agent to the full session, and respect native macOS titlebars. Discord's macOS back/forward buttons are hidden.

## Known limitations

The reported Windows freeze after inactivity remains unreproduced and unresolved. This release does not claim to fix it. Automated checks do not cover every plugin, signed-in account behavior, or physical voice and screen-sharing devices.

## Updating

Use the macOS arm64 DMG for Apple silicon or the Windows x64 Setup executable. ZIP archives, matching source, updater metadata, and SHA256SUMS are included.

Mac packages retain the persistent signing identity from 0.0.1-alpha.1. If you still use an older ad-hoc-signed alpha, quit Excord and replace it in Applications using the DMG once. Keep your profile to preserve login and settings. The app is self-signed and is not Apple-notarized; Windows packages remain unsigned.
