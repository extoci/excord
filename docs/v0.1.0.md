# Excord v0.1.0

Excord's first development build wraps Discord with a bundled Equicord catalog and local TypeScript plugin folders. The repository and its builds are private. The source is GPL-3.0-or-later.

## What works

- Apple silicon macOS DMG and ZIP, plus Windows x64 installer and ZIP.
- Bundled Equicord plugins, with the upstream manager, patcher, and APIs retained for compatibility.
- Local `index.ts` and `index.tsx` folders, optional native helpers, shared host APIs, and cached compilation.
- Cmd+R and Ctrl+R rebuild changed local folders and refresh Discord. Invalid folders report errors independently.
- Settings for creating and opening plugin folders, inspecting errors, and reading process metrics.
- An internal efficiency plugin that reduces animations and pauses decorative videos while the app is hidden.

## Performance choices

Excord skips the inherited splash and first-launch tour, caches injected scripts across refreshes, and bundles its modification runtime instead of downloading it at startup. The local compiler starts only when it needs to build a folder and stops when Electron quits. QuickCSS and theme watchers have one owner and close on refresh. A regression test that previously observed six notifications for one edit now requires one notification.

Rich Presence and process scanning default to off. When enabled, Rich Presence uses a bundled Node worker instead of a separate Bun executable. On the Linux build used during development, this replaced a 98,899,144-byte executable with about 60 KB of bundled JavaScript. This is a component size comparison, not a total application size or startup benchmark against Legcord.

Compatibility has costs. Excord retains the Equicord core and exports 1,422 shared renderer aliases for local plugins. That broadened the renderer bundle from about 3.1 MiB to 3.3 MiB. Some upstream settings still request a full restart. See the [compatibility record](compatibility.md).

The updated draft removes release source maps, ships English Chromium resources, and compresses Mac artifacts more densely. The unpacked Mac app is 18.5% smaller and the Windows portable app is 15.7% smaller than the initial draft. See the [exact size measurements](app-size.md) for archive sizes, methodology, and packaging costs. Discord's interface languages remain selectable; some browser menus and messages fall back to English.

## Verification

The release artifacts come from source commit `a92be78cc166bbb003f4ba650624bf2543da1787`. The [native verification run](https://github.com/extoci/excord/actions/runs/39207119776) records the results for each platform.

The checks cover strict ts-rust and TypeScript compilation, 16 compiler and origin tests, a real RPC handshake and activity lifecycle, and Electron running Discord's login page. The Electron checks exercise native plugin calls, shared host APIs, cached refreshes, syntax-error isolation, recovery, and the QuickCSS watcher regression. CSS updates also reach two simultaneous windows and continue after one closes. They run against source and the packaged ASAR. Separate checks launch the packaged executable and ASAR without an inspector, refresh five times, and require normal shutdown without a process kill. The Windows browser test permits automation cleanup after a file records its quit event; see the [verification details](releases.md).

Equicord is pinned to `e0e85c8d4f6dc73aac9368cf3f4b2200eac4d4b4`. The desktop base is pinned to Equibop `27219be3566589280c0c933b04753805381d3bc8`. Excord does not claim that every catalog plugin has been individually tested.

## Manual testing still needed

These builds are unsigned and unnotarized. The Mac package requires macOS 27 or later; the native CI runner uses macOS 26 on Apple silicon. Verify installation on the intended Mac before daily use.

No logged-in Discord account was available during development. Login, calls, camera permissions, screen sharing with audio, tray behavior, and notifications still need testing on physical Mac and Windows machines. A private GitHub repository also prevents unauthenticated installations from reading the release update feed.
